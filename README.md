# PMD releases

Installers for **Projects Management Dashboard** (PMD), Laudermarke's internal
project dashboard. Download them from the [Releases](../../releases) page.

| Installer | For |
|---|---|
| `PMD-Viewer-Setup-x.y.z.exe` | The manager's laptop (one per department) |
| `PMD-Studio-Setup-x.y.z.exe` | Each colleague's laptop |

The installers are per-user (no admin rights needed). Windows SmartScreen asks
once because they are not code-signed: choose **More info → Run anyway**.
After installation, both apps update themselves.

The apps only work with an invite from your department manager. Source code
lives in a private repository.
